Sketch Studio CAD dependencies

The CAD modules are bundled locally. No hosted CAD service, CDN or remote
geometry execution is required. Browser offline caches include both WASM files.
Electron distributes them with the application's dist/assets directory.

The kernel and solver are separate replaceable WebAssembly modules. To use
modified versions, rebuild the corresponding dependency from its source,
replace its JS/WASM package under node_modules and run npm run build.
The app imports these modules through their documented library interfaces.
Keep this notice and accompanying license texts with redistributed builds.
